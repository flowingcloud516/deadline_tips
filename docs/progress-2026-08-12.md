# Deadline Tips 项目进展记录

首次记录：2026-08-12

最近更新：2026-08-17

当前版本：0.2.0（Windows 10/11 x64 发布版本）

## 当前成果

### 核心业务

- 已建立任务模型，包含名称、详情、类型、截止日期、重要性、状态、周期规则及创建/更新时间。
- 支持一次性、每周、每月固定日、月末前 n 天任务。
- 日期计算已覆盖大小月、跨年和闰年 2 月。
- 重要任务始终只显示在“重要任务”区域，不与近期区域重复。
- 重要任务临期或逾期时红色高亮，并显示剩余天数和约剩余周数。
- 悬浮窗增加独立“周期任务”区域，展示所有待完成的非重要周期任务，不受近期天数范围限制；重要周期任务仍只进入重要区域。
- 周期任务的日期语义调整为整体结束日期，悬浮窗动态计算下一次发生日期，并同时展示下一次剩余天数和整体截止剩余天数。
- 增加与本地整点对齐的界面时钟，以及窗口聚焦/恢复可见时的即时刷新，修复跨午夜后剩余天数不更新的问题。
- 周期任务“完成本期”及下一截止日期计算已在应用服务中实现并通过单元测试。

### 悬浮窗

- 已完成无边框桌面悬浮窗，并移除外围底板。
- 标题精简为放大的 `DEADLINE TIPS`。
- 支持展开/收起、调整大小、位置和尺寸持久化。
- 使用 Windows 原生消息实现可靠拖动，已通过真实鼠标模拟验证。
- 支持任务管理入口，近期任务和重要任务双区域展示。
- 当前默认置顶。

### 任务管理

- 支持任务表格、状态/类型/重要性筛选及截止日期排序。
- 支持表格底部行内新增任务。
- 支持编辑、删除、状态和重要性修改。
- 日期输入使用原生日历控件，并提示手动输入格式为 `YYYY-MM-DD`。
- 管理窗口关闭按钮已修复，关闭后隐藏窗口。
- 编辑界面复选框与文字对齐问题已修复。

### JSON 数据存储

- 使用带 schema 版本的本地 JSON 文件保存数据。
- Rust 端实现原子写入，写入失败不会破坏原文件。
- 已提供 `StoragePort` 导入、导出及移动路径接口。
- 任务管理页显示当前数据文件路径。
- 用户可以通过 Windows 文件对话框选择新的 JSON 文件位置。
- 更改位置时先完整写入新文件，成功后才切换活动路径；失败时保留原文件和原路径。
- 路径配置跨程序重启保持有效。
- 任务管理页已增加 JSON 导入和导出入口；导入先校验文件并显示任务数量，用户明确确认后才原子覆盖当前数据，且不改变活动数据文件位置。

### Windows 桌面集成

- 已实现悬浮窗和任务管理双窗口。
- 已实现系统托盘的显示/隐藏悬浮窗、打开任务管理和退出功能。
- 窗口关闭默认隐藏，托盘退出才真正结束程序。
- 已禁用 Windows 控制台窗口，启动 EXE 不弹出命令行。
- 悬浮窗和任务管理窗口均不显示任务栏按钮，运行时仅保留界面和托盘图标。
- 界面在每个本地整点自动刷新，窗口聚焦或恢复可见时立即校准日期。
- 悬浮窗“−”按钮现在隐藏整个窗口，不再折叠任务内容；托盘可恢复显示。
- 默认每天本地时间 10:00 自动显示悬浮窗，时间可在任务管理窗口调整。
- 程序未运行或电脑休眠导致错过提醒时间时，当天启动或恢复后补显示一次。
